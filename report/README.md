# 关于report文件夹

**本文件夹存放电赛报告模板**

**最后我们拿去打印的报告找不到了，这个是初稿，跟最终版本有一点区别**

**注意，每年的电赛报告要求会有区别，以官网为准，以官网为准，以官网为准！！！**

## 1.文件命名

可以看到，我们把这个word文件命名为**E1234_小明_小白_小王**

这里E表示选题编号，1234表示队伍编号，后面按顺序填写队伍的三个成员，用下划线隔开

## 2.报告内容

我们那年的报告要求是分成摘要、系统方案设计与论证、理论分析与计算之类的好几个部分

## 3.其他

**1.** 报告应该不会查重或者查AI

**2.** 可以多放一点图和公式占空间，比如PID公式，实物图，流程图

**3.** 报告写得再好也不会给你加很多报告分，一般你做出来的题目越多，你的报告分就越高
